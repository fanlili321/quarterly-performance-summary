# quarterly-performance-summary

为范丽丽整理季度工作证据、撰写中文绩效自评，并在需要时填写绩效考核 Excel 的 Codex Skill。

> 本 README 是给同事看的快速导览；AI 执行时以 [`SKILL.md`](SKILL.md) 为准。

## 能做什么

- 汇总指定季度的飞书工作记录、群聊、云盘交付物和本地文件。
- 按“工作产出、AI 应用、团队协作/综合能力、需要提升”整理证据。
- 核对项目归属和遗漏项，避免把协作事项误写成个人成果。
- 生成有项目名、数量和实际影响的中文绩效自评。
- 按要求把最终文案和自评等级写入绩效考核 Excel，并保留原文件。

## 什么时候使用

同事提出以下需求时使用：

- “帮我整理 2026 年 Q3 工作总结。”
- “根据飞书记录写季度绩效自评。”
- “把自评内容填进这份考核表。”
- “检查季度总结有没有漏掉 AI、PPT 或线下活动相关成果。”

## 需要提供什么

- 年份和季度；如果上下文能够明确判断，可以不单独提供。
- 需要填写 Excel 时，提供绩效考核表文件。
- 如有未记录在固定资料中的成果，补充相应文件、链接或说明。
- 对相关飞书表格、群聊和云盘文件夹的访问权限。

## 会产出什么

- 按类别整理的季度工作证据清单。
- 可直接提交或继续修改的中文绩效自评文案。
- 如有 Excel 模板：一份保留原表结构和格式的已填写副本。
- 对证据不足、归属不明确或需要人工确认的事项给出提示。

## 工作流程

1. 确认季度和资料范围。
2. 从飞书工作记录、群聊、云盘和本地文件收集证据。
3. 分类整理并执行遗漏项、归属和数量核验。
4. 生成具体、可追溯的自评文案。
5. 如需填写 Excel，写入副本并检查数据和版式。

## 安装

```bash
git clone https://github.com/fanlili321/quarterly-performance-summary.git \
  ~/.codex/skills/quarterly-performance-summary
```

安装后可这样触发：

```text
使用 $quarterly-performance-summary，整理我 2026 年 Q3 的工作总结并填写绩效自评表。
```

## 依赖与权限

- Codex Skills 运行环境。
- 飞书表格、文档、云盘和群聊的相应读取权限。
- 处理 Excel 时需要可用的表格处理能力。
- 仓库中的 `scripts/fill_self_review.py` 用于写入约定结构的考核表。

## 使用边界

- 不凭空补充项目、数量或效率数据。
- 无法确认成果归属时，标为“协同/参与”或请用户确认。
- 不覆盖用户提供的原始 Excel，默认生成新副本。
- 不把群聊原文直接写进考核表，除非用户明确要求。

详细证据规则、写作标准和 Excel 字段约定见 [`SKILL.md`](SKILL.md)。
